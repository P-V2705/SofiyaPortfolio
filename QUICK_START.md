# ⚡ Quick Start: GitHub Auto-Sync

## 🔴 FIRST: Create Your GitHub Repository

1. Visit: https://github.com/new
2. Fill in:
   - **Repository name**: `SofiyaPortfolio`
   - **Owner**: `PV2705`
   - **Visibility**: Your choice (Public/Private)
   - ❌ **UNCHECK** "Add README", ".gitignore", "license"
3. Click **"Create repository"**

## 🚀 Then Run This:

```powershell
.\sync-to-github.ps1
```

## 🔄 For Continuous Auto-Sync:

```powershell
.\auto-sync-watcher.ps1
```

Leave it running while you code - it will auto-push every 30 seconds!

---

**That's it!** Your portfolio will now sync automatically to GitHub. 🎉
